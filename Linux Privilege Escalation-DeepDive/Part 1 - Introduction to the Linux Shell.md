User typically interact with a terminal, for example xTERM. 

<img width="655" height="210" alt="image" src="https://github.com/user-attachments/assets/ae6e8453-588b-4864-8d1b-70ec34f92844" />

xTERM is a terminal. This is a GUI program that allows us to communicate with the shell. 

<img width="677" height="277" alt="image" src="https://github.com/user-attachments/assets/ae953549-007d-4fc0-8dcd-9ad36940afd0" />

Now, this xTERM is running the shell, BASH. Bash is a command line Interpreter. We give commands to Bash in text, Bash understands its and executes them on the Operating System.

<img width="700" height="441" alt="image" src="https://github.com/user-attachments/assets/e438d5dc-fa9e-46fb-82de-4aead12e9dbe" />

Now, between terminal and Bash, there is TTY. Its like a channel where data is exchanged in two directions. So, from Terminal to Bash and from Bash to Terminal.

There are many types of shell for example /bin/sh

<img width="830" height="335" alt="image" src="https://github.com/user-attachments/assets/3cd00ba2-73ca-46c3-8590-b1571395dab3" />

Now, here we are using same terminal i.e xTERM but now the command line Interpreter is sh.
